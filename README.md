# Boyfriend's Day Interactive Surprise Website ❤️

A romantic digital scrapbook, interactive story, mini-game, memory vault, and cinematic surprise built for **Rishi Raghav Singh Pathania** by **Gauravi Ojhha**.

---

## ✨ Features & Sequence

1. **Welcome Screen**: Cinematic entrance gate, starry ambient lighting, and quick milestone tags.
2. **Our Story ("How We Became Us")**: Interactive timeline featuring Chitkara University beginnings, the historic **1 August 2025** first photo milestone, and the 21 August recorded vow.
3. **Our Memories ("Our Little Universe")**: Category-filtered responsive gallery (`Us Together`, `Rishi Vibes`, `Silly & Filters`, `Bikes & Rides`) with fullscreen lightbox and inline video cards.
4. **10 Things I Love About You**: Intimate stacked card swiper detailing his contagious smile, the Bullet 350 rides, the "Jai Gauravi Ki" loyalty, Arsenal matching kits, and more.
5. **Our Inside Jokes**: 3D interactive flip cards declassifying the Mustache & Razor Clause, the Alien Filter Chronicles, the North London Fitting Room Takeover, and PB 10 vs HP 88.
6. **The Soundtrack of Us**: Interactive vinyl player loading the actual **21 August unedited voice oath recording by Rishi**, with live scrubber, duration tracking, and collapsible Hindi transcript with English details.
7. **Boyfriend Quiz**: 6-question multiple choice interactive mini-game with real-time score tracking, personalized witty feedback, and celebratory confetti upon completion.
8. **Boyfriend Performance Review**: Satirical corporate appraisal dossier for Rishi Raghav Singh Pathania (Chief Boyfriending Officer in Gauravi's Heart), 5-star KPIs, and an indefinite contract renewal stamp.
9. **Future Us**: Interactive bucket list with real-time checkbox animations and milestone memories.
10. **One Last Thing**: Quiet cinematic bridge leading to the emotional climax.
11. **Final Surprise**: Staggered sentence-by-sentence emotional reveal, the sacred Shiva-Parvati blessing portrait, Gauravi's heartfelt letter, and an interactive love-shower Easter egg.
12. **Floating Music Player**: Non-intrusive floating vinyl dock with audio controls.

```bash
npm run dev

# 3. Open in your browser
http://localhost:3000
```

## 🚢 Deploying to Vercel (Production Ready)

This project is built and optimized for seamless deployment to [Vercel](https://vercel.com):

1. Push this project to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Happy Boyfriend's Day surprise website"
   git branch -M main
   git remote add origin <YOUR_GITHUB_REPO_URL>
   git push -u origin main
   ```
2. Log into **Vercel** and click **"Add New Project"**.
3. Import your GitHub repository.
4. Framework Preset will automatically detect **Next.js**.
5. Click **"Deploy"**! No environment variables required.
